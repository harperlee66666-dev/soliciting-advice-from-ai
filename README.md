# Soliciting Advice from AI

This repository contains the code, coded data and analysis outputs for the dissertation *Soliciting Advice from AI: Comparing Advice Requests in Reddit and WildChat*.

## Repository structure

- `code/` contains the notebooks used for data filtering, coding and supervised machine-learning analysis.
- `data/` contains the coded feature dataset used for the supervised machine-learning models.
- `results/` contains the final model results, tables and figures.

## Data

The modelling dataset contains coded features for 1,159 advice requests: 976 Reddit cases and 183 WildChat cases. Raw Reddit post text and WildChat conversation text are not included in the data folder.

## Analysis

The analysis compares how advice requests are framed on Reddit and WildChat and evaluates whether these framing features can predict the platform from which a request originated.
